# Personal Profile Generator

This is a simple Python project that collects user information and displays a formatted personal profile.

# Features
- Takes user input:
  - Name (string)
  - Age (integer)
  - City (string)
  - Skills (comma-separated string)
- Converts data types properly
- Formats and displays the profile using f-strings
- Cleans and organizes skills into a readable list
